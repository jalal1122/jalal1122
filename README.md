## 🚀 Featured Engineering Projects

### 🏢 [Wadaan Real Estate & Builders ERP](https://github.com/jalal1122/Wadaan-Real-Estate-And-Builder-ERP-System)
> **A high-precision, local-first enterprise desktop ERP and double-entry financial core.**
- **Tech Stack:** `Electron 44` • `Next.js 16 (Static Export)` • `React 19` • `Express 5` • `Prisma` • `PostgreSQL` • `TanStack Query v5`
- Engineered an offline-capable, local-first hybrid architecture yielding **<50ms transition times** across large-scale financial ledgers.
- Built double-entry bookkeeping engines ($\sum \text{Debits} - \sum \text{Credits} = 0.00$) backed by `Decimal.js` to eliminate IEEE-754 precision errors.
- Implemented Windows DPAPI (`safeStorage`) encryption for zero-leak local credential isolation and automated FIFO payment waterfalls.

- Built a centralized administrative control center synchronizing **30,000+ FMCG product listings**, production bundles, and dealer pricing tiers.
- Formulated compound MongoDB aggregation pipelines to process large-volume catalog queries with negligible latency.
